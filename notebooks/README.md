# Project Notebooks

This folder contains the Google Colab notebook used to develop the Automotive Supply Chain AI project.

## Notebook

**automotive_supply_chain_ai.ipynb**

The notebook covers:

1. Data loading and preprocessing
2. Exploratory data analysis
3. Demand forecasting using Random Forest
4. Inventory optimization and reorder recommendations
5. Supplier performance analysis
6. Retrieval-Augmented Generation (RAG)
7. Microsoft Foundry integration
8. Agentic AI and Python tool orchestration

## How to Run

1. Download the `.ipynb` notebook.
2. Open Google Colab.
3. Upload the notebook.
4. Install the required dependencies from `requirements.txt`.
5. Configure your Microsoft Foundry credentials securely using Colab Secrets.
6. Run the notebook cells in order.

**Note:** This project uses synthetic supply chain datasets for demonstration and learning purposes.
