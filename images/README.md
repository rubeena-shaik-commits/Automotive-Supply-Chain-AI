# Project Images

This folder contains visual documentation of the Automotive Supply Chain AI project.

## Contents

### 1. System Architecture Diagram
Illustrates the overall project workflow and integration of different AI components.

### 2. Machine Learning Workflow
Visual representation of the demand forecasting process using Random Forest Regression.

### 3. Inventory Optimization
Visual explanation of inventory position, safety stock, reorder point, and replenishment recommendations.

### 4. RAG and Agentic AI Workflow
Shows how supplier documents are retrieved using RAG and how the AI agent coordinates Python tools to generate supply chain recommendations.

## Purpose

These visuals provide a clear understanding of the project's architecture, workflow, and technical components.
